# 琴伴 · 钢琴 AI 陪练（H5）

面向钢琴初学者（0~3 级）的浏览器端钢琴陪练应用。支持 MIDI 电钢琴与麦克风两种输入方式，提供实时音符跟踪、逐音比对、四维评分与练习报告。

## 功能特性

- 🎹 **双输入模式**：Web MIDI API（零误差） / 麦克风 + YIN 音高检测（AudioWorklet 实时运行）
- 🎼 **标准曲谱格式**：MusicXML + OpenSheetMusicDisplay 渲染，支持音符高亮与实时光标跟踪
- 🎯 **实时反馈**：弹奏时曲谱光标跟随，已弹音符即时着色（正确/错音/八度）
- 📊 **四维评分**：音准 40% + 节奏 25% + 速度 15% + 完整度 20%
- 💡 **智能指导**：基于比对结果自动生成练习建议与键位提示
- 📖 **内置曲谱**：C 大调音阶、小星星、欢乐颂，支持扩展外部 MusicXML

## 技术栈

- Vue 3 + TypeScript + Vite
- OpenSheetMusicDisplay（曲谱渲染）
- Web Audio API（AudioWorklet + YIN 算法）
- Web MIDI API

## 快速开始

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 项目结构

```
src/
├── core/          # 核心引擎（YIN 检测、比对、评分、渲染器）
├── composables/   # Vue 组合式函数（练习流程、曲谱库）
├── components/    # 页面组件（曲目选择、练习、报告）
└── types/         # 类型定义
```

## 使用说明

1. 选择曲目与输入方式（MIDI 电钢琴或麦克风）
2. 设置练习速度（建议初学者用曲谱 BPM × 0.7）
3. 跟随曲谱光标弹奏，实时查看音符着色反馈
4. 完成后查看四维评分报告与练习建议

> 麦克风模式下请将设备靠近钢琴，保持环境安静。首次使用需授权浏览器麦克风权限。
